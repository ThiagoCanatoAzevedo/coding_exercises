## Documentation Template

The `name_exercise_ex.py` file contains a template for documenting your exercise progress. Each exercise should include:

```python
"""
Exercise annotations:
- Name: [Problem name]
- Date: [When solved]
- Development time: [Time spent]
- Difficulty (Leetcode): [Easy/Medium/Hard]
- Personal difficulty: [1-10 scale]
- Topic: [Algorithm/Data structure covered]
- Complexity: Time: O(...) | Space: O(...)
- Solved independently: [Yes/Hint/Solution review]
- Solution summary: [Brief explanation]
- Stuck points: [Where you needed help]
"""
```

**Shortcut**: Type `exnotes` and press ENTER in your editor for auto-completion.

## How to Use

### 1. **Solving New Problems**

- Create a new file in the appropriate platform and year directory
- Follow the naming convention: `problem_name.py` or `problem_name.js`
- Implement your solution
- Add documentation comments using the template format

### 2. **Organizing Exercises**

```
HackerRank/[YEAR]/[COMPANY]/[problem_file]
Leetcode/[YEAR]/[MONTH]/[problem_file]
```

### 3. **Tracking Progress**

- Document the date and time spent on each exercise
- Record difficulty assessment
- Note the complexity analysis (Big O notation)
- Track whether you solved it independently or needed help

### 4. **Version Control**

Initialize and maintain git history:

```bash
git init
git add .
git commit -m "Add exercise: [problem_name]"
```

## Tips for Success

1. **Document thoroughly** - Use the template to capture your learning
2. **Track metrics** - Record time complexity and actual performance
3. **Review regularly** - Revisit previous solutions for pattern recognition
4. **Practice consistently** - Dedicate time to daily or weekly exercises
5. **Analyze solutions** - Understand optimal approaches, not just working ones
6. **Experiment with languages** - Use different languages to reinforce concepts
